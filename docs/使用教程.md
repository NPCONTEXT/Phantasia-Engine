# 使用教程

## 开始之前
1. 设备用数据线连上电脑，或者走无线调试（设备和电脑连同一个 Wi-Fi）。无线第一次要配对：设备上「开发者选项 → 无线调试 → 使用配对码配对设备」，电脑终端运行 `adb pair 弹窗上的IP地址和端口`，输入弹窗上的配对码；以后开着无线调试就会自己连上（有时要等半分钟左右）。线和无线都连着时走线。鼠标停在右上角「环境自检」上能看到现在走的是有线还是无线；没连上时这个按钮是红边，停上去能看到原因。
2. 幻想引擎每次启动会自己跑一遍环境自检：全过就不打扰；有问题「环境自检」按钮变红边，点开看哪一项没过。设备的屏幕比例和脚本要的 2400x1504（16:10）不一样时，会直接弹窗问要不要切换（退出时自动还原）。
3. 每个工具开始前游戏要停在哪个画面，写在中间详情的说明里（点「展开说明」看全文）。

## 这些词是什么意思
- **歌单** = 工具列表；**专辑** = 一个游戏；**一首歌** = 一个工具（脚本）。
- **歌词** = 这个工具要做的每一步，一步一句。
- **播放** = 启动；**待播** = 排队；**顺序播放** = 一键串跑；**播放记录** = 运行记录。

## 播放一个工具
- 点歌单里的一行选中它，右下角的播放区就换成这首（没在播时：计时 00:00、进度格是空的、写着共几句），点播放区的 ▶ 播放。歌单里没有播放 / 停止按钮，播放、暂停都在播放区。
- 播放区会显示：工具名、已用时间、进度格、第几句；当前做到哪一步看中间的「歌词」页签。
- 没在播时，播放区的「下一首」= 换到下一首要播的：有待播就换成待播的第一首，没有就换成勾了的下一首（按序号），一首都没勾就是歌单里的下一行。
- **暂停**：播放区进度格右边的「暂停」，脚本停在下一次截图前，再点一下接着做（继续前最好把游戏放回暂停时那一页）。暂停时封面、进度都停住，已用时间不走，播放记录的耗时也不算暂停的时间。战斗中不能停：点了按钮会弹回，雨澜冒气泡说一声，打完这一场再点。每首歌都接上了：乐土(自动接管) 要等到选刻印、商店、剧情页才停，乐土浅层在备战页、队伍页、结算页能停，其余的歌在下一次截图前停；什么时候能停，点了暂停雨澜会告诉你。
- 中间「歌词」页签里，当前这一步会放大高亮；想看脚本的原始输出，点「运行日志」。
- 想停下这一首：点歌单那一行右边转圈的方块按钮。
- 有的歌词前面带勾选框（「崩坏3 · 记忆战场(周常)」的本期 BOSS、「崩坏3 · 超弦空间」的两个区）：勾哪个就打哪个，没勾的灰着、播放时跳过；勾选会记住，正在播放时不能改，改了下次播放生效。BOSS 名单是脚本播放时读出来的，还没读过就先播放一次；本期 BOSS 换了会自动清空勾选，要重新勾。
- 有的歌要先选角色（「崩坏3 · 乐土(自动接管)」用谁打）：说明下面一条「当前角色」，点「切换角色」打开角色面板，可以按名字或拼音首字母搜，点一下就换，下次播放生效；一次只能选一个，正在播放这首时不能换。名单里只有做好档案的角色，「已实测」= 完整跑通过，「待实测」= 刚加、还没整轮跑过。

## 一次跑多个（顺序播放）
- 点每行左边的方框，方框会变成序号，序号就是先后。
- 点歌单上方的「顺序播放 (N)」，先弹一个提示，确认后按序号一个接一个跑。
- 顺序播放是后台全自动的：日常类工具（崩3 日常、崩3 记忆战场、崩3 超弦空间、乐土、妮姬日常、妮姬协同作战、绝区零日常）开始前会先关掉自己的游戏、从冷启动开始，做完截一张结束画面再把游戏关掉，免得几个游戏同时开着把设备内存占满。关掉后设备的后台应用列表里可能还留着这些游戏的卡片，那只是系统缓存的画面，进程已经结束，不影响。
- 需要中途手动操作的工具，不建议加入顺序播放；乐土能从主界面自己进，可以放进去。
- 单独播放（选中后点播放区的 ▶）时，不会关游戏，做完游戏还开着。
- 某个工具没完成或出错，会记下结果接着跑下一个，不会卡住。
- **加进待播**：把歌单里的一行按住拖到播放区左边的封面上松手，就排到待播最后；拖着在封面上停一会儿，待播列表会展开，放到哪就插在哪。没在播时也能先排好，点 ▶ 时接在播放区那首后面。
- 鼠标移到封面上，右上角显示还有几首待播；点封面打开待播列表：按住一行拖动调先后，✕ 移出这一轮（不影响歌单）。拖动只改以后的顺序，不打断正在播的。
- 播放中「下一首」= 停掉当前这个，接着跑待播的下一个；没有待播时它变成「结束这首」（方块），点了先问一句，确认才停。
- 顺序播放开始后，歌单上方的「顺序播放」变成红色「停止连播」：点了 = 后面排着的全部取消，当前这首播完就停。想马上全部停，点右上角「退出(停止全部)」。
- 换到新的一首时，歌单会自动选中正在播的那首、滚到看得见的地方，中间切到它的「歌词」页；中途你点别的歌去看，不会被拉回来，下一首开始时才跟过去。

## 看进度
- 一步一步汇报的工具（崩3 日常、记忆战场、超弦空间、妮姬日常、妮姬协同作战、绝区零日常）：歌词里做过的变淡打勾，正在做的高亮，进度条一格是一步。
- 乐土这类循环型的工具：歌词高亮的是「现在在哪个环节」，歌词上方的灰色小条是从日志里读出来的要点（星级、第几层、打了几场等），进度条画的是星级 / 层数 / 关数。
- 乐土的「第 N 层」「积分」是脚本从游戏画面上读出来的。

## 看结果
- 歌单每行第二行：上次什么时候跑的、结果如何；鼠标停上去能看到完整时间、用的角色和常用时长。选中一首后，中间标题下面也写着常用时长。
- 「播放记录」页签：每次运行一条。没完成的步骤和原因直接写在下面，点「看日志」看那一次的完整日志；打开右上角「全部歌曲」看所有工具的记录。看过了点「知道了」，下面的红字收成一行灰字（验收结束截图时也会一起收起，记录还在）。
- 出了问题（步骤没完成、没达成目标、异常退出、启动不了）时，播放区的封面上会冒出雨澜的气泡，一直停到你点它；点一下跳到对应的播放记录。
- 顶栏「完成通知」开着时，每个工具跑完、整轮跑完都会弹一条系统通知。
- **结束截图**：每个要用设备的工具结束时（不管成功、没完成还是被你停下），幻想引擎都会截一张设备画面，挂在这次的播放记录上，歌单那一行会标「待验收 ›」，点它直接跳到这首的播放记录、那条记录描金框提示。点缩略图或「看大图」查看，看过点「验收」就把这张图删掉（记录还在）。

## 其它功能
- **调整歌单顺序**：在歌单里按住一行拖到别的位置（放在哪一行的上半 / 下半就挪到它前面 / 后面），或者选中后按键盘 ↑ ↓。只在同一张专辑里移动。
- **限时歌单**：歌单最底下的「限时歌单 · N 首」平时收起，点一下展开。限时活动的歌放这里，不参与顺序播放；右键歌单里那一行，选「移进限时歌单 / 移回歌单」。
- **监控**：点歌单上方的「监控」（开着是青色）：歌单收成正在播的那一行（没在播就是选中的那首），下面显示设备当前画面（只看，不存盘）；再点一下关掉，歌单恢复。
- **分辨率**：脚本按 2400x1504（16:10）写的。设备比例不一样时，启动时会弹窗问要不要切；也可以在「环境自检」窗口底部手动「设为 2400x1504 / 恢复设备分辨率」。退出时会自动还原。
- **进程树**：在「关于」窗口底部，看幻想引擎自己和它启动的工具进程（排查用）。
- **退出**：点「退出(停止全部)」，会停掉正在跑的工具并还原设备分辨率。

## 常见问题
- **点了播放提示「播不了：没有在线设备」**：检查数据线或无线调试，等右上角「环境自检」按钮不再是红边再点。
- **跑到一半想自己接手**：点播放区的暂停（战斗中要等打完），在设备上操作完回到原来那一页再点继续；不想让它接着跑了，点「结束这首」。
- **会不会乱花钱**：日常脚本都不点花水晶、花钻石的按钮；冒险委托只用免费刷新。
