# 日常脚本：认页面、点、点完核对

日常脚本 = 一串「步骤」，每步：确认在起点 → 按字找入口 → 等目标页面 → 做 → 核对做成了没有 → 回起点。
最短的现成例子是 `tasks/2026-11-01-妮姬协同作战/nikke_coop.py`（约 360 行，借同一个游戏日常脚本里的底层）；完整的是 `tasks/2026-10-06-妮姬日常/nikke_daily.py`、`tasks/2026-09-29-崩3日常任务/bh3_daily.py`、`tasks/2026-10-07-绝区零日常/zzz_daily.py`。

## 底层：照 `nikke_daily.py` 的 `Bot` 抄

| 方法 | 做什么 | 要点 |
|---|---|---|
| `grab()` | 截一张图 | 开头调 `pause_point()`（暂停就停在这里）；`exec-out screencap` 取原始 RGBA，比加 `-p` 取 PNG 快约 1 秒一张 |
| `ocr_img()` / `ocr()` | 识字，返回 `(字, x, y)` 列表 | 识字程序每行输出一条 JSON：text、conf、x、y、w、h，其中 x、y 是字框左上角（`ocr.swift` 开头注释写成了中心，以代码为准），要点中间就加半个 w、h；`ocr()` 再换算回基准坐标 |
| `tap()` / `swipe()` | 点、滑 | 传基准坐标，按实际分辨率换算后 `input tap / swipe` |
| `find()` / `find_all()` | 在上一次识字结果里找字 | `exact` 整词匹配；`region` 只在一块区域里找，避开别处同名的字 |
| `find_crop()` | 整屏漏读时裁一块再认 | 彩色按钮上的白字整屏常常认不出 |
| `tap_text()` | 找到字就点 | 先查禁点名单 `FORBID`（付费、补签、用活动道具的按钮名），命中就拒绝；它只看传进来的那几个字，挡不住付费弹窗里的「确认」「购买」 |
| `wait_any()` | 轮询等某几个字之一出现 | 代替写死的 `sleep`；返回认到的是哪个字 |
| `snap()` | 存当前截图 | 出岔子先存图再跳过，事后才对得上。妮姬那份存在 `/tmp/nikke`（`TMP`），新脚本改成工作目录下的 `shots/` 或 `logs.nosync/`（`.gitignore` 已排除），事后好找 |

另外两件每个游戏都要写：`ensure_game()`（没开就用包名启动，走过加载、公告、登录、标题页；只在认得的页面上点，不认识的画面只等不点。游戏本来开着时它当作已经进过游戏，停在哪个页面都直接返回，所以第一步之前也要回主界面）和 `to_lobby()`（按顺序试：关提示、关弹窗的 ×、点「关闭」、点底栏「大厅」或「主页」「返回」；都认不出就等两秒再看，不乱点，回不去就存图）。

## 主函数骨架（照 `nikke_coop.py` 的 `main`）

```python
STEPS = ["sign", "mail"]
NAMES = {"sign": "签到", "mail": "邮件一键领取"}      # 和 tools.json 的 tasks 一句一句对上


def main() -> int:
    bot = Bot()
    if not bot.ensure_game(False):                     # 没开就启动，开着就接管；进不去就每步都写原因
        log("完成：" + "，".join(f"{NAMES[k]}=没进到游戏" for k in STEPS))
        return 1
    result = {}
    for s in STEPS:
        log(f"== {NAMES[s]}")                          # 歌词跳到这一句
        bot.note = None
        if not bot.to_lobby():                         # 每步都从主界面出发；回不去就记原因、跳过这一步
            result[s] = "回不到主界面"
            continue
        try:
            getattr(bot, f"step_{s}")()                # 没做完就把原因写进 bot.note
            result[s] = bot.note or "ok"
        except Exception:
            traceback.print_exc()
            result[s] = "error"
    bot.to_lobby()                                      # 做完停在主界面，结束截图好认
    log("完成：" + "，".join(f"{NAMES[k]}={v}" for k, v in result.items()))
    return 0 if all(v == "ok" for v in result.values()) else 1
```

`log()` 打的行带 `[时:分:秒]` 前缀；`== 名字` 和最后的 `完成：…` 这两种行怎么被认，见 `接进幻想引擎.md`。

## 一步怎么写

- 入口按字找（`tap_text`），找不到就 `snap()`、写 `self.note = "主界面没找到某某入口"`、返回；别盲点坐标。
- 进页面后用 `wait_any` 等「只有这一页有」的字；等不到同样存图、写原因。
- 做之前先读状态：今天做过了（「已领取」、次数 0/3、红点没了）就跳过，不算没做完。
- 做完核对：再读一次页面，红点没了、数字变了、出现「已领取」才算成功；没变就写原因，别记 ok。
- 列表要滑着找：任务、商品、关卡的顺序会随完成状态变，按名字找到那一格，再点同一格里的按钮；往下翻时一次别翻太多，翻过头会漏掉。
- 玩法有开放时间的（周末活动、赛季、结算中、准备中）：先认出状态，没开放就写一句「本期没开」并跳过，别当成出错。

## 弹窗和岔路

- 每次识字后先过一遍「已知弹窗」：签到面板、活动海报、公告、新赛季提示、奖励窗、升级提示，关掉再接着做。弹窗经常晚一拍才出来，连着两次没认到才算收完。
- 关弹窗点 × 或「确定」；别点「点击空白区域关闭」那行字（可能点进活动页）。盲点空白处之前想清楚那里有没有菜单。
- 同一处「关闭」点两次画面都没变，它多半是状态字不是按钮，换「主页」「返回」走。
- 有的游戏在主菜单里按系统返回键会直接退出游戏；关菜单用游戏自己的按钮。
- 跳到别的 App（应用商店、分享网页）就按 Home 再把游戏拉回来；认到「需要更新客户端」就停下，不在商店里乱点。

## 认页面的办法

- 字：至少两个特征字，限定区域；识字会把数字读丢一位、把小数点读丢，文字比较用相似度。
- 没有字的（红点、发光、勾、图标）：看颜色占比，或者用模板小图（`tpl/*.png`，`cv2.matchTemplate`）。模板只裁按钮或图标那一小块，别把整屏截图放进仓库：整屏上常有账号、昵称。
- 颜色阈值、模板相似度的阈值，拿几十张真截图量过再定，两边各留余量。

## 资源和次数

- 花付费货币的一律不点。按钮名写进 `FORBID` 只是第一道；付费页、礼包弹窗要单独认出来（价格、货币图标、「购买」标题），认到就只点「取消」「返回」离开（例子 `nikke_daily.py` 的 `money_screen`、`leave_money_screen`）。通用的「确认」「购买」只在核对过是免费的弹窗里点。
- 体力、金币怎么花写成规则（先保证哪项、不够时从哪补、补到多少停），写进代码和歌的说明里；规则之外不自己多花。
- 每天几点刷新要记住：跨过刷新时间，前面读到的「做过了」就不作数，重读一次。
